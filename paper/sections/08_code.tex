\section{Code and Data Availability}\label{sec:code}
All experiments, tables and figures are produced by the accompanying repository, whose layout is listed in Table~\ref{tab:repo}. Library versions are pinned in \code{requirements.txt}. All five cohorts are publicly released, de-identified datasets (Table~\ref{tab:cohorts}), and no new patient data were collected; the TabPFN v2 weights are downloaded from the public Prior Labs release on first use and are used under the Prior Labs License~1.1 (\code{licenses/TabPFN-LICENSE.txt}). The deployed system is ``Built with PriorLabs-TabPFN''.
