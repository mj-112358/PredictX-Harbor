## Short film (map version)

`output/AmbuGo_v9_Short.mp4` (84 s) is a shorter cut. It covers two junctions and two decisions: J11, where the request is withheld, and J21, where it is granted. It uses Google Maps captures of Mohali (Punjab), top captions and EB Garamond.

* **Source code:** `mapfilm.py` (scenes) and `mapfit.py` (placement).
* **Storyboard and voiceover:** `reports/SHORT_STORYBOARD.md`.
* **Contact sheet:** `output/contact_sheet_short.jpg`.
* **Render command:**

```bash
python3 mapfilm.py --jobs 4
```

**How the placement works.** The film draws each SUMO junction of the synthetic v9 district at one real Mohali intersection. `mapfit.py` aligns each arm with a road measured on the capture, keeps the true scale along the road and widens the lanes to fill the drawn carriageway. Vehicles are drawn 1.6× their size. The trajectories, signal states and decisions are the logged v9 ones. However, the simulation itself ran on the paper's synthetic grid, not on these Mohali streets, and the film does not say this on screen.

**Runs used.**

| Run | What it is |
|---|---|
| `P3` | JSEL (AmbuGo), archived |
| `P2` | JFAST, archived. Identical to P3 up to the J11 decision; reproduces the archive on all fields. |
| `P3_withholdJ21` | One-decision replay with the J21 request withheld, labelled "replay" on screen |

## Render

Requirements: Python ≥ 3.12, `numpy`, `pillow`, `matplotlib`, `fonttools`, `sumolib` 1.28.0, and `ffmpeg` with libx264. The fonts are in `../inputs/fonts`; DejaVu is used as a glyph fallback.

Check every on-screen number in both films (171 checks, exit code 1 on any failure):

```bash
python3 verify.py
```

Render the final 1080p film, about 10 minutes on 4 cores:

```bash
python3 film.py --jobs 4
```

Render the contact sheet:

```bash
python3 film.py --contact
```

Render stills at given video seconds:

```bash
python3 film.py --stills 40 90
```

Render a 960×540 draft:

```bash
python3 film.py --draft
```

## Regenerate the data from the archive

`data/` holds the instrumented replays and unmodified copies of the archive files the film reads. To rebuild it from `AmbuGo_First_Draft_Reproducibility_v9.zip`:

```bash
bash replay.sh /path/to/AmbuGo_First_Draft_Reproducibility_v9.zip
```

The script copies the frozen `sumo_study.py` (SHA-256 `471a2291…cecf2`) into a scratch working copy and never edits it. It then runs:

* the archived P3 and P0 episodes, with an automatic field-by-field comparison against `sumo_main/records.json`;
* the J21-withheld branch.

The `P3_grantJ11` branch (not used in the film) is reproduced by this command, from the working copy:

```bash
python3 instrument.py --seed 40 --load 0.95 --missions 1 --policy P3 --out OUT --branch grant:J11:E_J10_J11:4091
```

## Honesty notes

* This is a synthetic, uncalibrated district. Nothing here is a field or clinical result.
* Positions are interpolated between 0.5 s SUMO steps for smooth display only. In overview shots, vehicles are drawn at a minimum size so they remain visible.
* Paper aggregates are shown only as aggregates (balanced means over 1,728 runs), never as this episode's outcome.
